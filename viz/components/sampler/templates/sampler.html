Data Sampler

Type or paste text, or load an example, then cut it into the training examples a language model learns from. Windows are what training actually consumes: a run of context size tokens, and the same run shifted one position along as the targets. Pairs unroll a window into the one-prediction-at-a-time form — which is what a causal model computes from a single window anyway, and the reason overlapping windows repeat work.
