# Agent instructions

This is a working environment for going through *Build a Large Language
Model (From Scratch)*: a Python package under `src/llm_from_scratch/`
implementing the book's pieces (tokenizer, vocabulary, attention, model,
training, finetuning) with a pytest suite under `tests/` and a small Flask
visualizer under `viz/` for poking at those pieces in a browser. See
`README.md` for setup, commands, and the full layout.

This is an educational, single-person codebase — no need for a
branching/PR workflow; commit straight to `main`.
